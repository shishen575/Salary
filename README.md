# 給料計算

バイト掛け持ち・夜勤ワーカー向けの給料計算Webアプリ（サーバー不要・ブラウザだけで動作）。

## 機能
- 複数の職場（名前・時給・深夜割増率）
- 勤務記録（職場・日付・開始〜終了）／翌日またぎ対応（22:00→06:00 など）
- 深夜割増（22:00〜5:00）の自動計算、24時間表記 ON/OFF
- 月次サマリー（職場別内訳＋合計）
- ライト／ダーク／自動テーマ、スマホ対応
- Googleドライブ同期（スマホ・PC間で共有）、暗号化バックアップ

## 使い方
`index.html` を開くだけで使えます（データはブラウザの localStorage に保存）。
端末間で共有するには、HTTPS で公開して Google ドライブ同期を設定します。

## Googleドライブ同期のセットアップ（初回のみ・無料）
1. このフォルダを GitHub Pages などの HTTPS で公開する（例: `https://<ユーザー名>.github.io/Salary/`）。
2. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成。
3. 「API とサービス」→「ライブラリ」で **Google Drive API** を有効化。
4. 「OAuth 同意画面」を設定（外部／テスト中で可。自分の Google アカウントを「テストユーザー」に追加）。
   スコープは `.../auth/drive.appdata` のみ。
5. 「認証情報」→「OAuth クライアント ID」→ 種類「ウェブ アプリケーション」。
   **承認済みの JavaScript 生成元** に 1 の URL のオリジン（例: `https://<ユーザー名>.github.io`）を追加。
6. 発行された `xxxx.apps.googleusercontent.com` を、アプリの「同期・設定」タブに貼り付けて「Googleドライブと同期」。
   他の端末でも同じ手順（クライアントIDの貼り付けのみ）で同期できます。

## セキュリティ設計
- **最小権限**: `drive.appdata` のみ。アプリ専用の非表示領域だけにアクセスし、Drive 内の他のファイルは見えません。
- **トークンはメモリのみ**: アクセストークンは保存せず、タブを閉じると消えます。クライアントシークレットは使用しません（ブラウザ向けの公開クライアントID方式）。
- **端末側暗号化（任意）**: パスフレーズ設定時、AES-256-GCM（PBKDF2-SHA256 / 60万回）で暗号化してから Drive・ファイルへ保存。パスフレーズは保存されません。忘れると復元できません。
- **厳格な CSP**: 外部通信は Google の認証ライブラリと Drive API のみ。インラインスクリプト不可。Google のライブラリは同期ボタンを押すまで読み込みません。
- **XSS対策**: 画面描画は `textContent` のみ（`innerHTML` 不使用）。
- **入力検証**: ローカル・Drive・読み込みファイルすべてのデータを型・範囲チェックしてから採用。
- **競合時の安全性**: 同期は「ダウンロード → 項目ごとにマージ → アップロード」。復号に失敗した場合は上書きしません。
- localStorage 内のデータ自体は平文です。共用PCでは「連携を解除」→「この端末のデータを削除」を使ってください。

## 計算ルール
- 基本給 = 時給 × 労働時間、深夜割増 = 時給 × 割増率 × 深夜時間（22:00〜翌5:00）。分単位で計算し、勤務ごとに円未満を四捨五入。
- 休憩時間の控除、開始＝終了（24時間勤務）は未対応です。
- 日をまたぐ勤務は開始日の月に計上します。
